# FAFLOW — Release Notes (v5.0 Enterprise)

FAFLOW Version 5.0 introduces enterprise operational personnel management, dedicated staff credit accounting, a reimagined faculty credit rewards intelligence hub, and a modern locked-viewport application layout.

---

## Key Highlights

1. **Operational Personnel & Manager Role**:
   - Institutional managers can now govern laboratory technicians and non-teaching administrative staff independently from academic faculty.
   - Dedicated laboratory room custody mappings.

2. **Staff Leave & Quota Management**:
   - Configurable baseline annual leave limits per staff member with automatic balance adjustments.
   - Manager duty credit awards for weekend practicals, examination duties, and facility maintenance.

3. **Faculty Substitution Credit Rewards Hub**:
   - Executive standing tiers (💎 Diamond, 🥇 Gold, 🥈 Silver, 🛡️ Standard).
   - Real-time coverage reliability scoring and transparent running balance ledger.

4. **Modernized Enterprise Layout**:
   - Static desktop sidebar with independent navigation scroll and pinned profile/sign-out footer.
   - Isolated main content vertical scrolling container.
