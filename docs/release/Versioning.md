# FAFLOW — Semantic Versioning Policy

FAFLOW follows the Semantic Versioning 2.0.0 specification (`MAJOR.MINOR.PATCH`):

- **MAJOR (`X.0.0`)**: Incompatible API changes, database schema breaking alterations, or architectural role hierarchy shifts.
- **MINOR (`0.X.0`)**: Backwards-compatible new features, new administrative views, or performance indexing additions.
- **PATCH (`0.0.X`)**: Backwards-compatible bug fixes, security patches, or documentation improvements.
